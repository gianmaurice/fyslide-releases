# Fyslide — releases

Downloads and release notes for the Fyslide desktop app for macOS and Windows (Beta). Binaries only; the source is not public.

- Download page: https://fyslide.com/download
- macOS, Apple Silicon: `Fyslide-<version>-arm64.dmg` · Intel: `Fyslide-<version>-x64.dmg` (signed and notarized by Apple)
- Windows 10/11 (Beta): `Fyslide-<version>-win-x64-beta.exe` (not code-signed yet; Windows may show a warning: More info → Run anyway; steps: https://fyslide.com/download/windows)
- `SHA256SUMS` lists the checksums; `latest.json` is read by the app's update check.

Fyslide needs a license (one license per device): https://fyslide.com/pricing
